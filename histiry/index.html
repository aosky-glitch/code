近代史四条主线

侵略与沉沦：鸦片战争《南京条约》开始沦为 → 第二次鸦片战争进一步加深 → 甲午《马关条约》大大加深 → 《辛丑条约》完全陷入半殖民地半封建社会深渊。
探索与近代化：洋务运动（近代化开端）→ 戊戌变法（思想启蒙）→ 辛亥革命（结束两千多年君主专制）→ 新文化运动（民主与科学）。
新民主主义革命：1919五四运动开端 → 1921中共成立 → 1927南昌起义与井冈山道路 → 1935遵义会议 → 1931—1945抗日战争 → 1949解放战争胜利。
现代中国：1949新中国成立 → 1956三大改造进入社会主义初级阶段 → 1978十一届三中全会改革开放 → 1997香港、1999澳门回归。

世界史关键节点

14世纪文艺复兴（人文主义）→ 15—16世纪新航路开辟（世界连为整体）→ 1689英国《权利法案》→ 1776美国《独立宣言》→ 1789法国大革命 → 18世纪60年代第一次工业革命（蒸汽时代）→ 1848《共产党宣言》→ 19世纪六七十年代第二次工业革命（电气时代）→ 1914—1918一战 → 1917十月革命 → 1929经济大危机与罗斯福新政 → 1939—1945二战 → 1947—1991冷战 → 1995世贸组织成立。
